## 🎯 About The Project

**KeyCraft** is a modern, interactive typing speed test platform designed to help users improve their typing skills in an engaging and visually appealing environment where your speed meet modern and best looking ui. In an era where digital communication dominates, typing efficiency is no longer just a skill—it's a necessity.

### 🌟 What KeyCraft has?  

- **Real-time Feedback**: Get instant insights into your WPM, accuracy, and error rate.
- **Beautiful UI/UX**: Enjoy a sleek, modern interface with smooth animations and transitions.
- **Progress Tracking**: Monitor your improvement over time with detailed statistics
- **Accessibility First**: Designed to be inclusive and user-friendly for all skill levels.

### 💡 The Vision

Our mission is to make typing practice enjoyable and effective. We believe that everyone deserves the tools to communicate faster and more accurately in the digital world. KeyCraft bridges the gap between practice and perfection.

--- 
## 🎯 Why Touch Typing Matters
- A crucial skill for developers, students, and professionals in daily digital tasks.
- Using all fingers improves typing speed, accuracy, and reduces hand fatigue.
- Better finger coordination enhances focus, productivity, and long-term efficiency.

## Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of web development (for contributors)
- Text editor or IDE (VS Code recommended)

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Surya-exp23/SP0515-Major-Project--KeyCraft-.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd SP0515-Major-Project--KeyCraft-
   ```

3. **Open with Live Server**
   - Install the Live Server extension in VS Code
   - In home-landing page folder Right-click on `index.html` and select "Open with Live Server"

4. **Or simply open the file**
   ```bash
    index.html
   ```
